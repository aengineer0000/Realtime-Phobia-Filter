This folder contains:
- trypo.py : Model builder for trypophobia classifier
Dataset source: Trypophobia (https://www.kaggle.com/datasets/cytadela8/trypophobia) - Combination of trypophobia and neutral images, 6.5k trypophobia + 10.5k neutral, 256 x 256 png format

- trypo_predict.py : Script to test model against test images
Initial tests using test images shows it accurately predicted correct classes (normal vs trypophobia-inducing pictures) with >99% confidence

- trypo_img.jpg, cat_img.jpg : Test images
